# Evaporate — дизайн-система

Редизайн лаунчера. Идея одна: **материя переходит в энергию**. Торрент конденсируется
в игру, интерфейс испаряется в момент запуска. Отсюда пламя в знаке, восходящие угли
в фоне и удержание кнопки «Играть» вместо клика.

Тема одна — тёмная. Земля почти чёрная с уходом в фиолетовый, никогда не чистый `#000`:
на OLED чистый чёрный даёт ступеньку на градиентах.

Семантика одна во всех темах и **не заменяет акцент**:
`ok #3BE39B` · `warn #FFC24D` · `bad #FF4D5E`.

Правила, которые легко нарушить:
- Насыщенная заливка акцентом — **не больше одного объекта на экран**. Это «Играть».
- `cool` только для чисел и графиков. Никогда для кнопок.
- Тень всегда чёрная и мягкая. Цветным бывает только свечение, и только у того,
  что реагирует на пользователя.
- `void` не осветляется даже под модальным окном.

**Потолок радиуса — 8 px.** Приборная геометрия: стадионов в системе нет,
кнопка запуска и статусы скруглены так же, как панели.

`3` чипы · `5` кнопки · `7` карточки · `8` панели и герой · `8` таблетки и круги.

Потолок меняется одним токеном — в настройках есть переключатель
**8 px · 24 px · Полный**, последний возвращает прежнюю шкалу
(6 / 10 / 16 / 22 / 30 и стадионы 99). Браузер режет радиус до половины
стороны, поэтому потолок заметен только на объектах крупнее 2 × потолка:
точки и мелкие чипы одинаковы во всех трёх режимах.

Потолок не распространяется на иконку приложения — её скругление диктует ОС.
Иллюстративные круги ему тоже не подчиняются: ядро ритуала — нарисованный
источник света с радиальным бликом, квадратное ядро ломает метафору.

Каркас окна: рейл `76` · топбар `58` · строка подсказок `32`.

Тени: покой `0 14 30 rgba(0,0,0,.55)` · поднято `0 26 54 rgba(0,0,0,.7)` ·
активно `0 0 0 1 accent/.4, 0 0 42 accent/.3`.

Токены радиуса для Flutter: `r1 3 · r2 5 · r3 7 · r4 8 · r5 8 · pill 8`.

## Эффекты

Двенадцать приёмов, разобранных в `evaporate-brand.html`. Собраны в один бюджет кадра
и отключаются пресетами качества «Эко» / «Полное» / «Макс» — пресет меняет плотность
частиц и разрешение шейдера.

1. Плюм пара — 5 октав fbm с двойным искажением домена, домен уезжает вверх
2. Угли — аддитивное смешивание, синусная турбулентность
3. Дым — два слоя размытого шума в режиме screen
4. Параллакс — слои глубины 5 / 14 / 30 / −8, текст против движения
5. Тепловое марево — `feTurbulence` + `feDisplacementMap`, только на заряде кнопки
6. Ореол — три тени 34 / 90 / 160 px вместо одного размытия
7. Подповерхностное рассеивание — источник внутри полупрозрачной оболочки
8. 3D-наклон обложки — до 11°, перспектива 700 px, спекулярная полоса
9. Круг заряда — три кольца на 16 и 24 с плюс дуга прогресса
10. Ударная волна и ирис — 190 vmax за 0.9 с, затем радиальное закрытие
11. Хроматическая аберрация — ±2.4 px, только на вспышке запуска
12. Плёночное зерно — плитка 128 px, overlay 5 %, убирает бандинг

`prefers-reduced-motion` останавливает цикл и оставляет статичный кадр.

## Состояния направления A

Направление **A · Витрина** развёрнуто до двадцати состояний внутри прототипа.
Панель «Состояния» в правом нижнем углу (клавиша `S`) — инструмент прототипа,
в продукте её нет.

| Раздел | Состояние | Что меняется |
|---|---|---|
| Библиотека | Обычное | Герой и полки, кнопка удержания |
| | Пусто · первый запуск | Знак во весь экран, два пути внутрь, зона перетаскивания |
| | Чтение каталога | Скелетон с бликом, первые 300 мс |
| | Не установлена | «Играть» → «Установить», строка про место на диске |
| | Есть обновление | Две кнопки и предупреждение про совместную игру |
| | Идёт установка | На месте кнопки — прогресс с паузой и отменой |
| | Игра запущена | Кнопка становится статусом с таймером, зелёным вместо янтаря |
| | Нет сети | Локальное работает, сетевое гаснет, плашки в топбаре янтарные |
| Загрузки | Две активные | Нормальный ход |
| | Нет раздающих | Янтарная полоса слева, прогресс тускнеет |
| | Нет места на диске | Красная полоса, точная нехватка в ГБ, выбор другого диска |
| | Ошибка проверки | Фиолетовая полоса, прогресс откатывается на проверенное |
| | Сеть пропала | Серая полоса, отсчёт до автоповтора |
| | Очередь пуста | Пунктирная рамка с приглашением вставить ссылку |
| Сохранения | Всё синхронизировано | Обычная лента |
| | Конфликт версий | Две колонки сравнения и третий выход — оставить обе |
| | Выгрузка идёт | Верхняя точка ленты с живой полосой |
| | Облако недоступно | Лента скрыта, объяснение и проверка связи |
| В игре | Оверлей | Кадры, 1 % редких, быстрые действия, друзья, фоновая загрузка |
| | Ритуал запуска | Шесть стадий, выброс частиц, вспышка, ирис → «Игра запущена» |

Правила для состояний ошибок:

- Цвет кодирует причину, а не громкость: **жёлтый** — ждём внешнего,
  **красный** — нужно решение человека, **фиолетовый** — система чинит сама,
  **серый** — просто пауза.
- У ошибки всегда есть число («не хватает 6.2 ГБ», «12 частей», «0 из 27 сидов»)
  и ровно одно главное действие.
- Ни одна ошибка не извиняется и не предлагает попробовать позже без объяснения,
  что именно произошло.
- Пустые состояния — не извинение, а приглашение: знак светится, угли продолжают
  подниматься, есть два реальных действия.
- Офлайн не блокирует игру. Гаснет только сетевое, и об этом сказано одной
  строкой под кнопкой.

В прототипе оверлей открывается клавишей `O`: `Shift+Tab` — это обратный обход
фокуса в браузере, его нельзя перехватывать. В десктопном приложении остаётся
`Shift+Tab`, как подписано в самом оверлее.

## Сценарий первого запуска

Восемь шагов от пустой библиотеки до запущенной игры. В прототипе сценарий
запускается пунктом «Первый запуск» в панели состояний; шаги листаются кнопками
или стрелками `←` `→`.

| # | Шаг | Что видит человек |
|---|---|---|
| 1 | Лаунчер только что установлен | Пустая библиотека: знак, два пути внутрь, зона перетаскивания |
| 2 | Вставили magnet-ссылку | Диалог «Добавить раздачу»: что внутри, что качать, куда |
| 3 | Загрузка встала в очередь | 0 % · скорость ещё оценивается, движок «разгоняется» |
| 4 | Качается | 41 % · 28.0 ГБ из 68.4 ГБ · осталось 4 ч 12 мин |
| 5 | Проверка файлов | Фиолетовая полоса: хеши сходятся, докачка идёт параллельно |
| 6 | Установка на диск | Прогресс встаёт на место кнопки в герое |
| 7 | Первая игра в библиотеке | Герой с чипом «Новое», одна обложка на полке |
| 8 | Первый запуск | Ритуал: шесть стадий, выброс частиц, вспышка, ирис |

Решения по пути:

- **Диалог добавления раздачи** — единственное место, где человек выбирает файлы.
  Строка «Игра» помечена «обязательно» и не отключается; всё остальное
  (озвучки, текстуры, саундтрек) снимается галочкой, и сумма с остатком
  на диске пересчитываются сразу. Внизу — btih-хеш: раздачу можно сверить.
- **Между шагами 3 и 4 нет отдельного «ожидания»**. Скорость честно
  показывается как оцениваемая, а не подменяется нулём или спиннером.
- **Проверка целостности не блокирует докачку** и покрашена фиолетовым —
  это система работает сама, а не ошибка.
- **Пустое состояние — точка входа, а не заглушка**: обе кнопки и зона
  перетаскивания запускают тот же шаг 2.

## Минимальное окно — 1280 × 720

На 720 по высоте от полки библиотеки был виден только заголовок: герой в полный
рост (374 px) вместе с секцией «Продолжить» съедали весь экран.

Правило для `max-height: 800px`:

- Герой фиксируется на 300 px, заголовок падает до 44 px, отступы до 18 px.
- Кнопки 50 px вместо 56.
- Карточки 152 px вместо 178 — полный ряд обложек помещается (низ на 667 px
  при строке подсказок на 679).
- **«Продолжить» складывается**: герой и есть кнопка «продолжить», а времена
  последних сессий остаются в подписях карточек. «Скоро на диске» остаётся
  под полкой, за прокруткой, — его же показывает раздел «Загрузки».
- Если в героя попадает блочный CTA (установка) или строка-примечание,
  описание скрывается, а заголовок становится однострочным. Проверено: все
  восемь шагов сценария и все пять состояний героя укладываются в 300 px
  без обрезки.

## Второй запуск

Первый запуск отвечает на вопрос «что это». Второй — на два других:
**что было, пока меня не было** и **где я остановился**. Отсюда две вещи,
которых в первом запуске не может быть в принципе.

**Дайджест «Пока вас не было»** — список того, что изменилось за время отсутствия.
Пять событий, у каждого одна строка, одна подпись и максимум одно действие:

| Событие | Что предлагается |
|---|---|
| «Орбита 7» докачана · 28.8 ГБ | Установить |
| Обновление 2.4.2 установлено ночью | Что нового |
| Антон К. прошёл Кузню Сумерек | Посмотреть |
| 2 сохранения выгружены · конфликтов нет | — |
| «Грозовой фронт» остановился · нет раздающих | Показать |

Кнопка «Всё понятно» **испаряет** панель: она разлетается частицами и сворачивается
в плашку топбара «Пока вас не было · 5», по которой её можно вернуть. Это тот же
приём, что в ритуале запуска, только в миниатюре — разобранное превращается в пар.

**Точка сохранения** живёт под кнопкой в герое: миниатюра главы, время,
размер и статус выгрузки, плюс «Другое» для выбора другой точки. Герой первого
запуска показать это не может — сохранений ещё нет.

Остальное в герое тоже меняется: надглавие становится «Вы остановились 41 минуту
назад», в чипах появляется глава и пометка «обновлена», а описание говорит не про
игру, а про конкретное место, на котором её закрыли.

Сценарий «Возвращение» в панели состояний проходит это за четыре шага:
новости → установка докачанного прямо из дайджеста → дайджест свернулся →
продолжение с той же секунды.

## Широкое окно — 1800 px и выше

На 2560 герой превращался в полосу 4.7 : 1, а обложка обрезалась по вертикали,
теряя композицию. Ширина уходила в пустоту.

Правило для `min-width: 1800px`:

- Библиотека становится двухколоночной: содержимое и **правая колонка 384 px**
  (420 px с 2200). Колонка держит дайджест, друзей и активные загрузки — то, что
  на узком окне живёт всплывающими панелями.
- Герой становится выше: `clamp(520px, 42vh, 660px)` вместо 520 максимум.
  На 2560 × 1440 это 605 px и пропорция 3.2 : 1 вместо 4.7 : 1.
- Заголовок растёт до 82 px, текстовый блок ограничен 760 px и 52 знаками
  в строке — длина строки не должна расти вместе с монитором.
- Карточки 224 px вместо 178.
- Загрузки раскладываются **в две колонки** вместо строк во всю ширину,
  тепловая карта роя — 48 столбцов вместо 32.

Дайджест на широком окне живёт в колонке, на узком — всплывает справа под
топбаром. Разметка одна, отличается только контейнер.

## Карточка игры

Старая карточка была самым слабым местом: в ней **не было кнопки запуска**. Можно
было открыть игру и не иметь возможности её включить. Плюс она не знала ни одного
состояния, появившегося позже.

**Липкая полоса действий** прибита к верху карточки и остаётся на месте при
прокрутке, поэтому главное действие доступно всегда. Она читает состояние
приложения, а не только поле игры:

| Состояние | Главное действие | Справа в полосе |
|---|---|---|
| Установлена | Играть · удержание 620 мс | Глава 5 · 62 % |
| Идёт игра | Идёт игра 01:04:12 · Оверлей · Завершить | Кузня Сумерек |
| Установка | Установка 41 % · Пауза · Отменить | осталось 12 мин, полоса внизу |
| Есть обновление | Обновить и играть 1,8 ГБ · Без обновления | установлена 2.4.1 |
| Не установлена | Установить 68.4 ГБ · Указать папку | свободно 214 ГБ |
| Качается | Идёт загрузка N % · Пауза | сиды и пиры, полоса внизу |
| В очереди | Скачать сейчас · Убрать из очереди | место в очереди |

Удержание в карточке — тот же механизм и то же кольцо заряда, что в герое.

**Четыре блока данных**, которых нет ни в одном магазине, потому что их знает
только лаунчер:

- **Ваша история** — часы всего, длительность последней сессии и когда она была,
  столбики последних семи сессий с подсвеченным пиком. Если игру ещё не
  запускали, вместо графика стоит честная строка, а не пустая рамка.
- **Достижения** — общая полоса прогресса и отдельной плашкой то, до чего ближе
  всего: «Собиратель · 37 из 60 реликвий · 62 %». Дальше сетка из пяти.
- **Состав на диске** — многоцветная полоса и список частей: игра, озвучки,
  текстуры, саундтрек. Часть «Игра» помечена обязательной и не снимается,
  остальные переключаются — та же строка `.filerow`, что в диалоге добавления
  раздачи, чтобы «что скачать» и «что лежит на диске» выглядели одинаково.
- **Раздача** — рейтинг, отдано, пиров сейчас. Этого нет у магазинов в принципе,
  а для торрент-лаунчера это нормальная часть карточки.

Справа ещё три блока: точка сохранения с миниатюрой и статусом выгрузки, друзья,
и список глаголов — проверить целостность, открыть папку, ярлык, раздача,
удалить с диска (с указанием, сколько освободится).

Обложка карточки — два слоя с параллаксом за курсором, как у героя.

## Раздел «Друзья»

Пятый раздел, `data-go="friends"` в рейле, `5` на клавиатуре. До этого друзья
жили кусками в трёх местах — карточка игры, оверлей, правая колонка — и нигде
не собирались вместе.

**Мысль, на которой построен экран:** у торрент-лаунчера социальный граф и рой —
один и тот же граф. Друг это не только «кто во что играет», но и «кто прямо
сейчас отдаёт вам данные». Второго нет ни у одного магазина, поэтому блок
«Раздают вам» стоит выше списка друзей, а первое число на экране — не количество
людей, а **скорость от них**.

| Блок | Что показывает |
|---|---|
| От друзей · прямо сейчас | 1,34 МБ/с и строка «83 % вашей скорости приёма дают друзья, а не рой» |
| Заявка в друзья | принять / отклонить, с числом общих игр |
| Общая библиотека | 31 игра есть хотя бы у одного друга: у всех 13, у половины 7, только у вас 11 |
| Сейчас в игре | крупные карточки с обложкой, аватаром, главой и временем сессии |
| Раздают вам | кто, что раздаёт, какую долю вашей скорости даёт, и полоса «друг против роя» |
| Все друзья | 12 человек: статус, число общих игр, действие по наведению |
| Лента | что происходило за неделю, включая «раздала вам 14.2 ГБ» |

Скорости сходятся с экраном загрузок: 402 КБ/с на «Орбиту» из 592, 870 КБ/с
на «Эхо» из 1.03 МБ/с. Социальный экран не выдумывает свои числа.

Состояния: обычное, заявка в друзья (плашка в топбаре), нет сети — в последнем
и «Сейчас в игре», и «Раздают вам» честно объясняют, что пиры от друзей
недоступны и скорость просядет, а не просто гаснут.

Точки статуса на аватарах кодируют то же, что везде: янтарный — в игре,
зелёный — в сети, серый — офлайн.

## Звук

Единственная часть языка, которой раньше не было вообще. Та же идея фазового
перехода, только слышимая: звуки не щёлкают, а поднимаются — низ уходит вверх,
материя переходит в энергию.

**Ничего не сэмплировано.** Все девять голосов синтезируются на месте через Web
Audio, как и обложки рисуются на canvas. Поэтому спецификация ниже и есть
реализация: числа в таблице — это буквально аргументы в коде.

| Голос | Класс | Длит. | Развёртка | Из чего |
|---|---|---|---|---|
| Касание | интерфейс | 30 мс | 2.2 кГц | Шум через highpass. Замечаешь, только когда выключишь |
| Нажатие | интерфейс | 70 мс | 520 → 300 Гц | Синус вниз + шумовой транзиент 16 мс |
| Смена раздела | интерфейс | 190 мс | 420 → 2300 Гц | Полосовой шум вверх, Q 1.2, линейная огибающая |
| Удержание | ритуал | 620 мс | 300 → 2600 Гц | Две пилы с расстройкой 7 центов через lowpass + саб 55 Гц |
| Готово | событие | 230 мс | 523 → 784 Гц | Две треугольные ноты вверх — единственный интервал в системе |
| Внимание | событие | 220 мс | 392 → 294 Гц | Одна нота вниз: ждём внешнего |
| Ошибка | событие | 300 мс | 300 → 150 Гц | Октава вниз, расстроенный дубль, транзиент |
| Испарение | событие | 420 мс | 280 → 5200 Гц | Шум вверх через узкий полосовой + шесть искр |
| Ритуал запуска | ритуал | 2600 мс | 30 → 5400 Гц | Саб вверх, шумовой подъём, 6 тиков по стадиям, удар на 92 %, хвост |

Правила:

- **Выключен по умолчанию.** Десктопное приложение, которое шумит на первом
  запуске, враждебно — и браузер всё равно молчит до жеста. Включение и есть жест.
- **Звук никогда не громче картинки.** Выключен эффект — выключен и его звук;
  пресет «Эко» глушит ритуал вместе с частицами.
- **Интерфейс живёт в 200 Гц – 4 кГц**, всё ниже 120 Гц принадлежит ритуалу.
  Они не спорят за одно место в спектре.
- **Длительности по классам: 120 / 400 / 2600 мс.** Голос длиннее своего класса —
  ошибка, а не выразительность.
- **Пассивные события молчат.** Пока вы в другом разделе, докачка и заявка
  в друзья не звучат — они ждут в дайджесте.
- Шина идёт через компрессор (порог −18 дБ, 4 : 1), поэтому ритуал не может
  перекричать интерфейс, даже если они совпали.

Настройки — в разделе «Настройки»: общий тумблер, громкость, три класса по
отдельности и фоновая отдушина (тихий дышащий шум ниже 210 Гц, по умолчанию
выключена). Каталог с прослушиванием и графиками огибающих — раздел 07
в `evaporate-brand.html`.

## Настройки

Раньше это была плоская сетка из четырёх панелей, которая росла пристройками —
последней туда въехал звук. Теперь экран навигируемый: липкая колонка слева,
поиск по строкам и **десять разделов, которые можно назвать вслух**.

Облик · Эффекты · Звук · Библиотека · Загрузки · Раздача · Сохранения · Запуск ·
Клавиши · О программе

**Поиск** ищет не только по подписям строк, но и по заголовкам панелей: слово
«скорость» живёт в «Расписании скорости», а не в названии опции, поэтому запрос
раскрывает весь раздел «Загрузки». Совпадение в строке подсвечивается, пустые
разделы и их пункты навигации прячутся, а если не нашлось ничего — экран честно
это говорит и предлагает, что попробовать.

Два места, которые есть только у этого продукта:

- **Расписание скорости** — 24 часа, которые красятся курсором. Янтарные часы
  идут без ограничения, серые держат предел 2 МБ/с. По умолчанию ночь (0–7)
  открыта: канал всё равно простаивает. Точка сверху показывает текущий час.
- **Папки с играми** — список с полосой занятости и остатком на каждом диске,
  а не одно поле пути. Видно, куда встанет следующая установка.

Плюс разделы, которых требует торрент-движок и не требует магазин: до какого
рейтинга раздавать, ограничивать ли отдачу в игре, раздавать ли друзьям без
лимита. И таблица клавиш — те же, что в строке подсказок внизу окна.

## Профиль

Аватар в рейле раньше никуда не вёл. Теперь это шестой раздел (клавиша `6`).

**Репутация здесь — рейтинг раздачи, а не «уровень».** Поэтому он стоит
четвёртой плашкой, подсвечен янтарём и повторяется отдельной панелью: отдано
1.4 ТБ против полученных 581 ГБ, и строкой — «на каждый скачанный гигабайт вы
вернули рою 2.41». Ни один магазин такого показателя не имеет.

**Год игры** — тепловая карта 52 × 7, тот же приём, что активность роя
в загрузках. Считается по-настоящему: числа под ней (дней, часов, самая длинная
серия) выводятся из той же сетки, а итог «часов в играх» складывается из года
и прошлых лет, поэтому плашка и карта не спорят. Русские числительные
склоняются — «193 дня», а не «193 дней».

Дальше: часы по играм с обложками, кому отдали больше всего, недавние
достижения, устройства и приватность — четыре тумблера, каждый про то, что
именно видят друзья, включая «находить меня по коду», который выключает вас
из поиска целиком.

Код для друзей (`EVP-8К4М-ТРПЛ`) смыкается с разделом «Друзья», где есть
«Добавить по коду».

## Режимы просмотра

Направления B, C и D собраны по-настоящему. Каркас у всех четырёх общий, поэтому
строить заново ничего не пришлось: **B и D встали видами библиотеки**, а
**C забирает весь экран**, потому что в нём рейл и топбар не нужны.

Переключатель из трёх иконок стоит в топбаре рядом с хлебной крошкой и виден
только на библиотеке. «Пульт» открывается кнопкой рядом или клавишей `P`.

### B · Стена

Плотная сетка обложек, фильтры в шапке (Все · Установлены · Качаются · Недавние),
счётчик справа. Выделенная игра разворачивается **на первой позиции**, занимая
3 × 2 клетки: так сетка не прыгает при каждом клике, в отличие от разворота на
месте. В большой плитке — чипы, название, «Играть» и «Подробнее»; в маленьких имя
появляется по наведению, а состояние (процент, очередь) живёт бейджем.

### D · Терминал

Моноширинная таблица: статус точкой, обложка 22 px, название, жанр, версия,
размер, часы, последний запуск. **Любой столбец сортирует** — повторный клик
переворачивает порядок, активный подсвечен янтарём со стрелкой. Строки ходят
`↑` `↓`, `Enter` запускает. Свет применяется скупо: только выделенная строка и
точки статусов.

### C · Пульт

Полный экран для дивана и геймпада. Карусель из пяти обложек, центральная крупная;
фон — размытая копия выбранной игры, поэтому тема меняется вместе с ней. Заголовок
до 58 px, две большие кнопки, подсказки по кнопкам геймпада вместо клавиш.
`←` `→` листают, `Enter` запускает, `Esc` выходит; по боковым обложкам можно
кликать.

Состояния всех трёх лежат в панели прототипа группой «Режимы».

**Найденная по дороге ошибка каскада:** класс `big` на большой плитке стены совпал
со служебным `.big` для крупных чисел в панелях — плитка унаследовала 50 px
и Unbounded, из-за чего «Подробнее» рендерилось заголовком. Модификатор
переименован в `wt-big`. Это ровно тот случай, от которого спасает
пространство имён у модификаторов.

## Профиль другого игрока

Открывается кликом по любой строке в разделе «Друзья» — из карточек «сейчас
в игре», из списка и из блока «Раздают вам». В хлебной крошке стоит имя, сверху
кнопка «Все друзья».

**Чужая страница полезна сравнением, а не копией своей.** Поэтому она устроена
относительно вас:

- **Первое крупное число — не его часы, а «раздал вам»**, и оно подсвечено
  янтарём. Для торрент-лаунчера это и есть суть отношений между двумя людьми.
- **Общие игры** показаны расходящимися полосами: ваши часы влево янтарём,
  его — вправо цианом, от общей середины. Сразу видно, где он вас обгоняет.
- **Раздача между вами** считается в обе стороны: 214 ГБ вам против 96 ГБ ему,
  и строкой — «69 % трафика между вами шло от него».
- **Достижения, которых нет у вас** — не весь его список, а разница.

**Скрытое показано скрытым, а не отсутствующим.** На своей странице есть четыре
тумблера приватности; если бы чужая просто не отрисовывала выключенное, они
ничего бы не значили. Поэтому:

- плашка «Часов в играх» остаётся на месте и говорит «скрыто» с замком;
- вместо карточки «сейчас играет» — объяснение, что человек не показывает игру
  и что это один тумблер в его профиле;
- панель «Что скрыто» перечисляет выключенное списком и заканчивается строкой
  «Это его выбор, а не ошибка» со ссылкой на те же настройки у вас;
- год игры и достижения просто не показываются, раз часы закрыты.

Два состояния в панели прототипа: **Антон К.** открыт полностью, **Игорь В.**
скрыл часы, достижения и текущую игру. У остальных десяти друзей профиль
выводится из их же данных, а не копируется с Антона.

## Виджеты Flutter

Первый слой перенесён из макетов в код. Запуск:

```
flutter run -d windows
```

Открывается каркас окна; галерея компонентов — в «Настройках → Разработка».

| Файл | Что внутри |
|---|---|
| `lib/design/tokens.dart` | `EvColors` (3 облика), `EvRadii` (3 потолка), `EvMotion`, `EvSpace` |
| `lib/design/typography.dart` | `EvType` — Unbounded, Onest, JetBrains Mono через `google_fonts` |
| `lib/design/theme.dart` | `EvTheme extends ThemeExtension`, `buildEvTheme`, `context.ev` |
| `lib/widgets/ev_icon.dart` | `EvIcon`, `EvMark` — SVG прямо из `design/assets` |
| `lib/widgets/ev_surfaces.dart` | `EvPanel`, `EvChip`, `EvPill`, `EvBar`, `EvSectionHeader` |
| `lib/widgets/ev_controls.dart` | `EvGhostButton`, `EvMiniButton`, `EvSwitch`, `EvSegmented`, `EvOption` |
| `lib/widgets/ev_play_button.dart` | Кнопка запуска с удержанием и кольцом заряда |
| `lib/widgets/ev_game_card.dart` | Карточка полки с процедурной обложкой |
| `lib/art/key_art.dart` | `EvCoverPalette`, генератор прототипа, сцена обложки и слои героя |
| `lib/art/ev_art.dart` | `EvArtCache` — растры кадров, `EvCover` — обложка из кэша |

| `lib/gallery/gallery_page.dart` | Витрина всех компонентов, переключатели облика и радиуса |
| `lib/glass/` | Стекло: материалы, свет на кромке, капля выбора, преломление — см. раздел «Стекло» |

Решения, принятые при переносе:

- **Токены приходят через `ThemeExtension`**, а не через глобальные константы.
  Виджет читает `context.ev` и ничего не знает ни об облике, ни о потолке
  радиуса — поэтому переключение того и другого не требует правок в виджетах,
  а `lerp` даёт плавный переход между темами.
- **Иконки не перерисовывались.** `EvIcon` берёт те же SVG из
  `design/assets/icons`, которые собирает `build_assets.py`: один источник
  правды, макеты и приложение не могут разойтись.
- **Обложки рисуются процедурно** — перенос `paintScene` из прототипа шаг
  в шаг, с его же генератором случайных чисел, поэтому кадры те же, а не
  похожие. У раздачи картинки может не быть, а серый прямоугольник на полке
  хуже, чем сгенерированный кадр. Подробнее — в разделе «Герой библиотеки».
- **Кнопка запуска удерживается, а не нажимается.** 620 мс, кольцо заряда
  рисуется `CustomPaint` поверх кнопки через `PathMetric.extractPath`.
  Нажатие не запускает игру — это проверяется тестом.

Две ловушки, которые поймали инструменты:

- Поле `type` в `ThemeExtension` перекрывало геттер `ThemeExtension.type` —
  ключ, по которому `ThemeData` находит расширение. Поиск темы сломался бы
  молча. Поле переименовано в `text`, тест на это есть.
- Дыхание ядра — единственная бесконечная анимация в системе, и из-за неё
  `pumpAndSettle` не досчитывается до покоя, а окно перерисовывается вечно.
  Теперь она останавливается при «уменьшить анимацию»
  (`MediaQuery.disableAnimationsOf`).

Чего ещё нет: экраны разделов, звук.

### Каркас окна

Рейл 76, верхняя полоса 58, экран раздела и строка подсказок 32 — поверх
фона. Размеры и поведение сняты с прототипа, а не придуманы заново.

| Файл | Что внутри |
|---|---|
| `lib/shell/ev_shell.dart` | `EvShell` и `EvShellController`: раскладка, смена разделов, клавиши |
| `lib/shell/ev_rail.dart` | `EvRail`, `EvRailItem`, `EvAvatar`, `EvBottomNav` для узкого окна |
| `lib/shell/ev_top_bar.dart` | `EvTopBar` — крошка, поиск, показатели; `EvKey` |
| `lib/shell/ev_hints_bar.dart` | `EvHintsBar` — строка подсказок из работающего продукта |
| `lib/shell/ev_palette.dart` | `showEvPalette`, `EvCommand` — поиск и команды |
| `lib/shell/ev_section.dart` | `EvSection` — шесть разделов в порядке обхода |
| `lib/screens/` | Библиотека (герой и полки), Загрузки (приборы и раздачи), Настройки (облик и эффекты), таблички остальных разделов |
| `lib/data/sample_data.dart` | Демо-содержимое, пока нет движка |

**Окно.** Windows-раннер: заголовок «Evaporate», старт 1440 × 900, минимум
1280 × 720 полезной площади. Система ограничивает внешний размер, поэтому
`WM_GETMINMAXINFO` добавляет рамку и заголовок через
`AdjustWindowRectExForDpi` — с DPI того монитора, где окно сейчас. Рамка
тёмная всегда и не следует ни за темой Windows, ни за её акцентом: на
Windows 11 заголовок красится в цвет земли, текст — `ink2`, кромка — `line`
(`DWMWA_CAPTION_COLOR` и соседи). Windows 10 этих атрибутов не знает и
оставляет просто тёмный заголовок.

**Раскладка.**

- Боковое поле — `EvSpace.gutterFor(окно)`, ступени прототипа: 2,2 % ширины
  в пределах 16…30; на окнах до 800 по высоте — 18; от 1800 по ширине —
  30…44, и ширина сильнее высоты.
- Уже 760 px рейл становится нижней панелью 60 px, строка подсказок и
  показатели в полосе пропадают. На Windows до этого не доходит — это для
  веба и узких превью.
- Карточки полки идут ступенями: 178; на окне до 800 по высоте — 152
  (134, если оно ещё и не шире 1120); от 1800 по ширине — 206, от 2200 — 224.

**Смена раздела.** Экран проявляется за 340 мс, а поднимается на 10 px и
дорастает с 99,4 % за 440 — садится, а не выскакивает. Уходящий гаснет
линейно за 200. Повторный выбор открытого раздела возвращает экран к началу;
для этого главный скролл экрана объявляется `primary: true`, а вложенные
списки контроллер экрана не подхватывают. При «уменьшить анимацию» смена
мгновенная.

**Клавиши** — те же, что в строке подсказок и в прототипе:

| Клавиша | Действие |
|---|---|
| `1` … `6`, цифровой блок | Раздел по номеру |
| `Ctrl+Tab`, `Ctrl+Shift+Tab` | Следующий и предыдущий раздел по кругу |
| `/`, `Ctrl+K` | Поиск и команды |
| `Tab`, стрелки, `Enter` | Фокус по элементам и нажатие |
| `Esc` | Закрыть палитру, выйти из галереи |

- Пока фокус в поле ввода, цифры и слэш принадлежат полю. `Ctrl+Tab`
  работает и оттуда — он ничего не печатает.
- Слэш узнаётся и по символу, и по физической клавише: в русской раскладке
  на месте «/» стоит точка.
- У каркаса своя область фокуса (`FocusScope`). Поле ввода по Enter снимает
  с себя фокус и отдаёт его ближайшей области; будь это маршрут над
  каркасом, клавиши молча перестали бы работать. Тест на это падает, если
  заменить область обычным `Focus`.

**Фокус с клавиатуры.** `EvFocusable` даёт кнопкам рейла, аватару и поиску
фокус, `Enter` и пробел. Рамка — 2 px `hot2` с отступом 3 px, как
`:focus-visible` в прототипе, и только при навигации с клавиатуры: клик
мышью обводки не оставляет. Подсказка рейла выходит и по наведению, и по
фокусу. Карточка в фокусе поднимается, как при наведении, но фокус получит,
когда у неё появится действие — лист игры.

**Поиск и команды.** Затемнение с размытием, панель 620 px на 15 % высоты,
не больше девяти строк. Ищет по названию и по подписи — «хоррор» находит
игру. Стрелки выбирают, `Enter` выполняет, `Esc` и клик мимо закрывают.
Внутри игры, разделы и команды облика и радиуса. `Enter` на игре
открывает её карточку, `Shift+Enter` и клик с Shift запускают её
ритуалом, минуя карточку; игру, которой ещё нет на диске, такая строка
открывает в «Загрузках».

**Фон** — живая атмосфера, см. следующий раздел.

**Что нашёл живой кадр окна.** Тесты проверяли размеры, но три вещи видно
было только на снимке настоящего окна:

- Знак в рейле не рисовался — оставалось одно свечение. В `build_assets.py`
  контур ядра был разбит на две строки без пробела на стыке, и Python склеил
  «-4.8» и «0» в «-4.80». Браузер рисует контур до ошибки, `flutter_svg`
  не рисует ничего и молчит. Исправлено в источнике, логотипы пересобраны,
  а `test/assets_test.dart` разбирает каждый SVG из выгрузки.
- Поиск и показатели не доходили до правого поля: `Flexible` рядом со
  `Spacer` забирал половину свободного места и не отдавал остаток. Теперь
  крошка в `Expanded`, положение правой группы проверяется тестом.
- Заголовок окна был оранжевым — это акцент Windows, включённый для
  заголовков. Отсюда цвета рамки выше.

**Демо-данные.** Движка раздач нет, поэтому полка, скорость и счётчики —
из `sample_data.dart`. Число активных загрузок выводится из самой
библиотеки, а не пишется рядом вторым числом. «Сохранения», «Друзья»
и «Профиль» пока честные таблички: что здесь будет и как сюда попасть —
навигация работает уже сейчас.

### Атмосфера

За интерфейсом три слоя прототипа в том же порядке снизу вверх: плюм пара
на шейдере, восходящие угли и плёночное зерно. Включаются в «Настройках →
Эффекты» вместе с уровнем «Эко / Полное / Макс» и ограничением до 30 к/с.

| Файл | Что внутри |
|---|---|
| `shaders/plume.frag` | Плюм: 5 октав fbm с двойным искажением домена, как в прототипе |
| `lib/atmosphere/ev_atmosphere.dart` | `EvAtmosphere`: кадры, курсор, жизненный цикл окна, рисование |
| `lib/atmosphere/ember_field.dart` | `EvEmberField` — симуляция углей, без Flutter |
| `lib/atmosphere/static_backdrop.dart` | Неподвижный фон на случай, когда шейдер недоступен |
| `lib/design/effects.dart` | `EvEffects` — настройки эффектов, отдельно от облика |

**Плюм** рисуется в отдельную картинку уменьшенного разрешения и
растягивается на окно — как холст WebGL в прототипе: 55 % при «Полном»,
не меньше 30 % и не больше 100 %, умноженное на плотность экрана, но не
больше двух. Есть и вторая причина: координата пикселя в шейдере у Impeller
локальная, а у Skia (веб) экранная. В картинке без преобразований они
совпадают, и один шейдер работает везде. Курсор сдвигает плюм на 11 %
с тем же сглаживанием, что в прототипе, но пересчитанным во время: на
120 Гц пар не летит вдвое быстрее.

**Угли** рисуются одним `drawAtlas`: белый спрайт свечения окрашивается под
каждую искру, светлое ядро — поверх. Число искр — ширина окна / 17
в пределах 34…104, умноженное на уровень эффектов.

**Кадры идут, только пока их видно.** Свёрнутое окно и страница под
непрозрачным маршрутом не рисуют ничего. Неактивное окно — 30 к/с таймером,
а не пропуском кадров тикера: тикер будил бы процессор 60 раз в секунду
впустую. «Уменьшить движение» оставляет неподвижный кадр прототипа, t = 8.
Если шейдер не загрузился, рисуется неподвижный фон — тот, что прототип
показывает без WebGL.

**Две ошибки прототипа, найденные при переносе.** Обе исправлены и в
`evaporate-launcher.html`, и в приложении.

- *Плюм был невидим.* Холст WebGL был запрошен без предумноженной альфы.
  Шейдер уже умножает цвет на альфу, смешение `SRC_ALPHA` умножает второй
  раз, браузер — третий. Замер `readPixels` в браузере: альфа не выше
  18/255, вклад в яркость — не больше 1 %. Живой фон был включён, но его
  не было видно. Три варианта отрисованы и сравнены: буквальный перенос
  невиден, «альфа один раз» — мутный дым на весь экран, а обычный
  предумноженный холст даёт пар, поднимающийся снизу, при тёмном верхе под
  интерфейс. Взят последний; тест держит яркость кадра между крайностями.
- *Угли жили у нижней кромки.* Жизнь искры копилась в миллисекундах, а
  записана была в кадрах (340…900). Искры гасли за секунду, новые рождались
  под окном и не успевали подняться: через пару секунд все угли были
  в нижних 30 px. Теперь жизнь — 5,7…15 с, и угли поднимаются через весь
  экран; первая партия стартует в разных фазах, а не разгорается разом.

Обе ошибки не видны на скриншоте одного кадра — только в движении или
в замере, поэтому на каждую есть тест, и тесты проверены на поломку:
с миллисекундами самая высокая искра оказывается на y = 873 из 900.

### Стекло

Пар поднимается за интерфейсом — значит, интерфейс есть то, на чём он
оседает. Навигационный слой сделан из стекла: рейл, полосы каркаса,
панели и всё, что лежит поверх картинки, размывают фон под собой,
ловят свет на кромке и гнут кадр у края. Приём тот же, что в iOS
(frosted glass и Liquid Glass), но источник света здесь свой — курсор.

| Файл | Что внутри |
|---|---|
| `lib/glass/glass_style.dart` | `EvGlassStyle` — материалы: иней, поповер, линза, капля, чип |
| `lib/glass/ev_glass.dart` | `EvGlass` — сам материал: фон, заливка, свет, нажатие |
| `lib/glass/glass_surface.dart` | `EvGlassLight` и блик на кромке вершинами |
| `lib/glass/glass_lens.dart` | Преломление фона: слой, шейдерный фильтр, запасной путь |
| `lib/glass/ev_droplet.dart` | `EvDroplet` — капля выбора, которая перетекает |
| `lib/glass/ev_scroll_edge.dart` | Мягкий край полосы: размытие ступенями вместо линии |
| `shaders/glass_lens.frag` | Линза: SDF кромки, преломление, дисперсия |

**Материалов два**, как в iOS, плюс две служебные разновидности:

| Материал | Размытие σ | Заливка | Кромка | Где |
|---|---|---|---|---|
| **Иней** | 22 | `surface` 62 % | 0.40 | Рейл, полосы, панели, строки «Продолжить» |
| Иней поповера | 30 | `raised` 72 % | 0.30 | Палитра команд, подсказки рейла |
| **Линза** | 6 | `sub` 42 % | 0.62 + преломление 13 px | Чипы, «Подробнее», бейджи на обложках |
| Капля · чип | — | по месту | 0.22 · 0.42 | Выбранное, клавиши, кнопки внутри стекла |

Правила, которые легко нарушить:

- **Стекло — для слоя, который лежит поверх содержимого**, а не вместо
  него: полосы, панели, кнопки над кадром. Обложка, график и текст
  стеклом не притворяются.
- **Стекло на стекле фон второй раз не читает.** Кнопка в полосе,
  клавиша, капля выбора берут `backdrop: false`: под ними уже размыто,
  а каждое чтение фона — отдельный проход по кадру.
- **Общий снимок фона — только для стёкол одного слоя, которые не
  перекрывают друг друга** (`BackdropGroup`): полосы каркаса, чипы
  в герое, строки «Продолжить». Снимок берётся на первом из них,
  поэтому всё, что нарисовано между ними, в фон соседа не попадёт.
- Размытие **ограничено прямоугольником стекла** (`bounded blur`):
  соседнее содержимое не затекает под кромку, и край остаётся
  непрозрачным.

**Свет — это курсор.** В iOS блик на стекле ходит за наклоном
устройства; на столе наклона нет, зато есть курсор, и он же двигает
пар и слои героя — курсор берётся тот самый, сглаженный (`EvPointer`).
Кромка стекла считается четвертью круга: её нормаль поднята над
плоскостью, поэтому ближняя к свету сторона разгорается, дальняя
отвечает слабым вторым бликом — свет выходит из стекла с другой
стороны. Цвет блика — белый, подогретый акцентом облика: тема задаёт
температуру источника света, и стекло это показывает. Без курсора
(галерея, тесты, «уменьшить движение») свет стоит слева сверху —
оттуда же, откуда горячий край у кнопки «Играть».

Кромка рисуется **вершинами**, а не обводкой: у обводки один цвет
на весь периметр, а стеклу нужно, чтобы яркость считалась в каждой
точке по её нормали. Лента в два ряда с растушёвкой по краям заодно
даёт сглаживание без `MaskFilter`.

**Капля выбора** — то самое «жидкое» в жидком стекле. Выделение не
гаснет и не зажигается на новом месте, а перетекает: передний край
уходит раньше заднего (кривые сдвинуты на 28 %), а поперёк капля
сужается ровно настолько, насколько вытянулась вдоль, — жидкость не
прибавляет в объёме. Так ходит выбор в рейле, в нижней панели, в
палитре команд и в сегментированных переключателях.

**Преломление** (`ImageFilter.shader`) работает только под Impeller —
то есть в приложении на Windows, но не в вебе и не в тестах. Шейдер
получает фон в пикселях экрана, поэтому ему нужен прямоугольник стекла
в тех же координатах; стекло же переезжает вместе с прокруткой и
параллаксом, не перерисовываясь. Поэтому у линзы свой слой: он
пересчитывает преобразование на каждой сборке сцены и меняет униформы
до того, как сцена уйдёт в движок, — кадр в кадр. Если выше по слоям
кто-то открыл свой буфер (слой прозрачности при смене раздела, цветной
фильтр, другое стекло), координаты перестают совпадать — в таком кадре
стекло остаётся матовым, это заметно меньше, чем преломление, съехавшее
на полэкрана.

Проверено снимками из `flutter test --enable-impeller`: с ним тестовый
движок — Impeller, и шейдерные фильтры работают, поэтому линзу видно
не только в живом окне. Замер: при масштабе 1 и 2, под сдвигом и
в связке с размытием прямоугольник шейдера совпадает со стеклом
пиксель в пиксель; внутри слоя прозрачности — не совпадает, отсюда
правило выше.

**Экран уходит под полосы.** Рейл стал плитой с отступом 8 px от кромок
окна, верхняя полоса и строка подсказок лежат поверх экрана, а экран
занимает всю высоту и узнаёт о занятом месте из отступов `MediaQuery`.
Поэтому при прокрутке заголовок героя и полка уезжают под стекло, а не
упираются в него, — ради этого стекло и нужно. Резкую границу под
полосой снимает мягкий край: три ступени размытия и затемнения вместо
линии (в iOS это scroll edge effect).

**Настройки.** «Стекло» выключает размытие целиком — остаётся заливка
поплотнее и та же кромка; «Преломление стекла» выключает линзу
отдельно и само гаснет там, где движок её не умеет. Уровень эффектов
тоже участвует: «Эко» размывает мягче (×0,55) и линзу не включает,
«Макс» усиливает дисперсию в полтора раза.

**Две ловушки, найденные при переносе.**

- *Холст нельзя запоминать до отрисовки содержимого.* Блик рисуется
  поверх детей, и если взять `context.canvas` заранее, а ребёнок
  откроет свой слой — а внутри стекла бывает другое стекло, — прежний
  холст уже закрыт, и кадр падает на пустом указателе. Холст берётся
  заново после `super.paint`.
- *Вершины нужно закрывать сразу.* `ui.Vertices` — нативный объект;
  если оставить его сборщику мусора, тот успевает добраться до него
  раньше, чем кадр доедет до экрана.

с размытием, двухточечный градиент виньетки, свечение кромок как
`shadowBlur` холста (сигма — половина размытия), прозрачность холста —
в цветах градиентов. Генератор — mulberry32 с арифметикой 32-битных целых
JS; умножение собрано из 16-битных половин, чтобы и в вебе не терять
разряды. Раньше обложки были приближением — размытые пятна вместо дымки,
три хребта вместо двух, другой генератор, — теперь в приложении ровно те
кадры, что в макете. Тест сравнивает их с сетками средних цветов, снятыми
с холстов прототипа (`test/fixtures`): разница в среднем меньше единицы
из 255, в худшей клетке — две, и это JPEG прототипа.

**Кадр рисуется один раз.** Под Impeller кэша растра нет: сцена с тремя
размытыми слоями, нарисованная прямо в дереве, перерисовывалась бы на
каждом кадре окна, а атмосфера идёт на 60 к/с. Поэтому `EvArtCache` рисует
кадр в текстуру — как холст прототипа в `toDataURL`, — а дальше рисуется
текстура. Обложка растрируется ровно в свой размер в пикселях экрана. Слои
героя — ступенями масштаба по четверти, от 0,5 до 2,5: перетаскивание края
окна перерисовывает кадр только на границе ступени. Размытия масштабируются
вместе с растром — это тоже проверено тестом.

**Параллакс.** Слои лежат с запасом 9 % (небо) и 6 % по краям и сдвигаются
за курсором на 5, 14 и 30 px; текст — на 8 px навстречу им, по вертикали
всё на 0,55 от этого. Курсор один на окно, как `mx, my` в прототипе:
`EvAtmosphere` отдаёт свой сглаженный `EvPointer`, поэтому пар и обложка
догоняют курсор одинаково. Если живой фон и искры выключены, атмосфера
заводит кадры, только пока курсор догоняется и за ним следит герой,
и останавливает их, когда он встал. Выключается в «Настройках → Эффекты»
и при «уменьшить движение».

**Удержание «Играть».** 620 мс, переключатель — в «Настройках → Эффекты».
С клавиатуры так же, как в прототипе: `Пробел` или `Enter` держат заряд,
отпущенная клавиша сбрасывает его; рамка фокуса — только в режиме
клавиатуры. Пока заряд идёт, кадр дрожит тепловым маревом — в прототипе
это фильтр `feTurbulence` + `feDisplacementMap`. Здесь слои режутся на
полосы в пиксель, и каждая сдвигается вбок гладкой волной с периодом 33 px
по вертикали, как у шума фильтра, — одна текстура и один `drawAtlas` на
слой. Размах — до 2,5 px: предел фильтра 4,5, но шум `fractalNoise` редко
отходит от середины дальше четверти. Шейдер здесь рискован: у Impeller на
OpenGL ось выборки текстуры перевёрнута, а проверить это можно только на
живом окне. Марево нарастает за первые 20 % заряда и гаснет вместе со
сбросом.

**Ступени раскладки** — `EvLibraryLayout`, в порядке CSS, позднее сильнее:

| Окно | Герой | Заголовок | Кнопки | Обложки | Колонка |
|---|---|---|---|---|---|
| обычное | `clamp(340, 52vh, 520)` | `clamp(34, 5.4vw, 68)` | 56 | 178 | — |
| до 800 по высоте | 300 | `clamp(28, 3.4vw, 44)` | 50 | 152, до 1120 — 134 | — |
| от 1800 по ширине | `clamp(520, 42vh, 660)` | `clamp(56, 3.6vw, 82)` | 56 | 206 | 384 |
| от 2200 | — | — | — | 224 | 420 |

Текст героя не шире `min(620, 72 %)` (от 1800 — 760 и 64 %, от 2200 — 840
и 58 %), описание — 46 знаков (`46ch`, 52 на широком). На низком окне
«Продолжить» складывается, отступы текста — 18 px. «Продолжить» — колонки
`auto-fill` не уже 268 px (330 на широком), пустые остаются пустыми, как
в CSS. Правая колонка — друзья и активные загрузки; скорости в ней
выводятся из самих загрузок, и та же сумма стоит в верхней полосе.

**Что открывается отсюда.** «Подробнее», строки «Продолжить» и обложки
полок открывают карточку игры, удержание «Играть» — ритуал запуска;
оба раздела ниже. Ссылка «Все игры»
из заголовка полки появится вместе со «Стеной», дайджест «Пока вас не было»
в правой колонке — вместе со сценарием второго запуска.

**Найдено по дороге.**

- *Ошибка прототипа:* свечение за фигурой заливало прямоугольник от 0,4
  высоты кадра, и его верх резал круг градиента — в небе героя стояла
  горизонтальная ступенька. Исправлено в обоих местах: свечение рисуется
  кругом, а сетка слоя для теста снята заново с исправленного прототипа.
- Текст без явной разрядки наследовал под Material `letterSpacing: 0.25`
  из `bodyMedium` и выходил шире прототипа: описание героя переносилось на
  третью строку, а в браузере занимает две. Разрядка в `EvType` теперь
  задана явно.
- Ширина описания — 46 знаков «0» шрифта, а шрифты Google догружаются уже
  после первого кадра. Мерка, снятая с запасного шрифта, оставалась бы
  навсегда: в веб-сборке описание шло в три строки. Герой пересчитывает её,
  когда `systemFonts` сообщает о новом шрифте.
- «Подробнее» в прототипе набрано кеглем страницы — 15 px, а не 14.
- У трёх сессий «Продолжить» в прототипе одно время — «вчера в 23:40»,
  заготовка макета. Здесь у каждой своё.

**Тесты.** На библиотеке ядро «Играть» дышит бесконечно, и `pumpAndSettle`
не дождался бы покоя: тесты каркаса досчитывают экран фиксированной
секундой. Новые тесты проверены поломкой: другой сдвиг в генераторе, шум
по столбцам, обратный знак параллакса, кадры, которые не встают, отпускание
клавиши без сброса, пробел без заряда, удержание мимо настроек. Мельче
сетка не ловит: сдвиг звёзд на процент или другая ширина лучей не видны
ни глазом, ни в средних по клеткам.

### Ритуал запуска

Удержание «Играть» в герое и `Shift+Enter` в палитре запускают игру
ритуалом поверх всего окна: затемнение, ядро с кольцом заряда, шесть
стадий, выброс искр, вспышка, ударная волна и ирис, который возвращает
окно. Тайминги и кривые сняты с прототипа — его часы подменялись, а
анимации CSS ставились на паузу и перематывались, — и тест сверяет с теми
же кадрами непрозрачность вспышки, диаметр волны и проявление затемнения.

| Файл | Что внутри |
|---|---|
| `lib/launch/ev_launch_ritual.dart` | `showEvLaunchRitual`, `EvLaunchRitual` — маршрут, часы, затемнение с ирисом, искры, волна, полоса |
| `lib/launch/ritual_timeline.dart` | `EvRitualTiming`, `EvRitualFrame` — ход ритуала как функция от времени |
| `lib/launch/ritual_core.dart` | `EvRitualCore` — кольца, дуга прогресса и шар ядра |
| `lib/atmosphere/ember_paint.dart` | Рисование искр — общее для атмосферы и ритуала |

**Ход.** Время — от нажатия.

| Время, мс | Что происходит |
|---|---|
| 0 | Затемнение проявляется за 300 (`ease`), искры срываются вверх |
| 0…2600 | Кольцо и полоса идут линейно, шесть стадий сменяются каждые 433 |
| 2600 | Удар: вспышка 0.9 → 0 за 500, волна 20 px → 190 vmax за 900 |
| 2600…3600 | Ирис раскрывает окно из центра |
| 4020 | Затемнение уходит за 300 с последним кадром на экране |

Выключенный ритуал («Настройки → Эффекты») — то же затемнение с ядром и
названием, но на 0,9 с и без стадий. При «уменьшить движение» — оно же,
без проявления и ухода, кольца стоят, шар не дышит, вспышки нет, что бы
в настройках ни было выбрано.

**Окно под ритуалом.** Ритуал — модальный маршрут: клавиши каркаса и
курсор до окна не доходят, а после ритуала фокус возвращается туда, где
был. Пока пустота закрывает окно целиком — от конца проявления до удара —
маршрут объявляет себя непрозрачным, страница под ним не рисуется и
атмосфера не тратит кадры. На ударе ирис открывает окно, и оно рисуется
снова.

**Шар ядра** растрируется один раз: тени в 50 и 130 px размываются не на
каждом кадре дыхания, а готовый растр только масштабируется до 1,11 и
светлеет на 20 %. Искры ритуала — тот же `EvEmberField`, что в атмосфере,
но свой: выброс не трогает угли за интерфейсом.

**Чего ритуал пока не делает.** Прототип после него возвращает библиотеку
как была; состояние «Игра запущена», где кнопка становится статусом,
придёт вместе с остальными состояниями героя. Звук ритуала — вместе со
звуком.

**Ошибки прототипа, найденные при переносе.** Все исправлены и в
`evaporate-launcher.html`, и в приложении.

- *Испарения интерфейса не было видно.* Выброс шёл на холсте углей под
  интерфейсом, а через 300 мс его закрывала непрозрачная пустота ритуала.
  К тому же у выброса осталась жизнь `1400` — миллисекунды, записанные до
  перевода жизни углей на кадры; в кадрах это 23 с, и искра не успевала
  разгореться. Теперь выброс живёт 1,4 с и летит над пустотой, под ядром:
  в прототипе холст углей на время ритуала переезжает внутрь затемнения.
- *Волна была квадратной.* Её радиус брался из потолка скругления, и при
  8 px волна расходилась скруглённым квадратом. Ударная волна из ядра —
  иллюстративный круг, как само ядро, и потолку не подчиняется.
- *Затемнение уходило сброшенным.* Полоса, кольцо, подпись и ирис
  сбрасывались в начале ухода, и раскрытое окно на 300 мс снова закрывала
  пустота с «Подготовкой среды».
- *Журнал оставался от прошлого запуска:* при втором запуске под
  «Подготовкой среды» стояла «передача управления».
- *Ирис зависел от частоты кадров:* по 2,2 % за кадр — на 144 Гц вдвое с
  лишним быстрее. Теперь это секунда времени.
- *Посреди окна светилась точка.* У закрытого ириса отверстие было
  нулевым, но мягкий край в 1 % оставлял пятно в 17 px, сквозь которое
  просвечивал интерфейс. В покое отверстие отрицательное.
- *Палитра запускала что угодно:* `Shift+Enter` на качающейся игре
  начинал ритуал. Теперь такая строка ведёт в «Загрузки» — как обложка
  в «Стене» и в «Пульте».

**Найдено по дороге.**

- Жирное слово в названии героя было не ExtraBold, а лёгким начертанием,
  которое движок утолщал сам: `copyWith(fontWeight: w800)` у стиля
  `google_fonts` оставляет загруженное семейство `Unbounded_300`.
  `EvType.displayBold` теперь отдельный вызов `google_fonts`, и его берут
  и герой, и ритуал. Остальные места, где вес задан через `copyWith`,
  ждут той же правки.
- При «уменьшить движение» Flutter ускоряет обычные контроллеры в двадцать
  раз: удержание «Играть» сжималось с 620 мс до 31, а короткое затемнение
  мелькало 45 мс вместо 900. Удержание и часы ритуала — отсчёт, а не
  анимация, и ускорению больше не подчиняются.
- Текст маршрута без `Material` получает стиль-заглушку Flutter — жёлтое
  двойное подчёркивание. Видно только на живом кадре, и теперь на это
  есть тест.
- Строка стадии в CSS — 16,5 px, а абзац Flutter округляет высоту до 17,
  и ядро съезжало на четверть пикселя. Высота задана явно.
- В `README` и в брендбуке ирис «закрывает кадр», а прототип раскрывает им
  окно из центра. Перенесено как в прототипе.

**Тесты.** `test/launch_test.dart`: ход ритуала против кадров прототипа,
выброс, раскладка на 1280 × 720 и 1440 × 900 теми же числами, что
в браузере, модальность и возврат клавиш, короткое затемнение,
«уменьшить движение», остановка атмосферы под пустотой, искры над
пустотой по пикселям, `Shift+Enter` в палитре. Проверены поломкой: жизнь
выброса в 1400 кадров, искры под пустотой, сброс до ухода затемнения,
ирис по кадрам, прозрачный маршрут, окно, которое не открывается после
удара, ускоренные часы и удержание, строка стадии в 17 px, `Shift+Enter`
как `Enter`, запуск чего угодно из палитры, текст без `Material` и
отверстие ириса в покое.


### Карточка игры

Всё, что лаунчер знает об игре, на одном листе: обложка с параллаксом,
липкая полоса действий и четыре блока данных, которых нет ни в одном
магазине. Открывается из «Подробнее» в герое, из строки «Продолжить»,
с обложки на полке и из палитры по `Enter`; закрывается по `Esc`,
крестиком в углу обложки и кликом мимо листа.

| Файл | Что внутри |
|---|---|
| `lib/sheet/ev_game_sheet.dart` | `showEvGameSheet`, `EvGameSheet` — маршрут, лист, обложка, полоса действий |
| `lib/sheet/sheet_blocks.dart` | История, достижения, состав на диске, раздача, сохранение, друзья, глаголы |
| `lib/data/game_facts.dart` | `EvGameFacts` — то, что знает лаунчер: часы, сессии, части, рейтинг |
| `lib/art/key_art.dart` | `paintSheetWaves` — передний слой обложки карточки |

**Числа те же, что в макете.** `cardData` прототипа выводит их из сида
игры — того же, по которому рисуется обложка, — поэтому `EvGameFacts`
повторяет не значения, а сам вывод: тот же генератор и тот же порядок
обращений к нему. Без часов в игре семь чисел на сессии не тратятся, и
сдвиг в одном месте увёл бы все остальные. Проверено сравнением
с открытой карточкой в браузере: 24 ч, 1 ч 30 мин, рейтинг 1,25,
отдано 85,5 ГБ, 8 пиров, части 54,0 / 8,2 / 6,2 / 7,9 / 2,4 ГБ.

**Липкая полоса** прибита к верху листа и остаётся на месте при
прокрутке, поэтому главное действие доступно всегда. Она читает
состояние игры: установленную запускает удержание — то же, что в герое,
и тот же ритуал; у качающейся на месте «Играть» стоит холодная кнопка
с процентом, у стоящей в очереди — «Скачать сейчас» с размером. Справа
полоса говорит, где вы остановились, сколько сидов или какая эта игра
в очереди. У игры из героя полоса читает состояние окна — «идёт игра»,
«установка», «обновление», «не установлена», — как `cardState`
в прототипе; см. раздел ниже.

**Обложка** — два слоя из растрового кэша, как у героя, но курсор здесь
свой: слои ходят за ним в пределах самой обложки, на 6 и 22 px.

**Четыре блока.** История: часы всего, последняя сессия и семь столбиков
с подсвеченным пиком; пока игру не запускали, вместо графика честная
строка. Достижения: общая полоса, ближайшее отдельной плашкой, сетка из
пяти. Состав на диске: многоцветная полоса и части, которые снимаются, —
кроме обязательной. Раздача: рейтинг, отдано, пиры — то, чего нет
у магазинов. Справа — точка сохранения, друзья в этой игре и список
глаголов; глаголы пока без действия, как и кнопки пауз: движка нет.

**Найдено по дороге.**

- *Обложка закрывала собой полосу действий.* Кадр вписан по «cover»
  и по высоте вылезает за обложку вдвое; `CustomPaint` рисует за своими
  границами, а `Stack` этого не режет. В прототипе у обложки
  `overflow:hidden`, здесь — `ClipRect`. Видно было только на живом
  кадре: разметка при этом правильная, кнопка «Играть» лежала на своём
  месте под кадром.
- *Полосы состава, достижений и рейтинга не рисовались.* Цветная доля
  без ребёнка в `Row` получает нулевую высоту, а заливка во
  `FractionallySizedBox` без выравнивания встаёт по центру. Теперь
  у каждой полосы есть тест на высоту и на левый край.
- Столбик истории с подписью дня не влезал в свои 62 px и рисовался
  с жёлто-чёрной лентой переполнения. В CSS подпись лежит внутри той же
  высоты, а столбик ужимается, — здесь так же.

**Тесты.** `test/sheet_test.dart`: сведения об игре против чисел
прототипа, открытие из четырёх мест, `Esc` и крестик, раскладка листа
(1080 × окно − 80, обложка 234, полоса 71), удержание в полосе,
снятие части и обязательная часть, карточка игры в очереди. Проверены
поломкой: обложка без обрезки, доли без высоты, заливка по центру,
обязательная часть, `Esc`, палитра, карточка, не закрытая перед
ритуалом, и лишний вызов генератора.


### Состояния героя

Шесть состояний игры в герое — те же, что `HERO` в прототипе. Состояние
меняет не только кнопку: надглавие, описание, чипы и строку под кнопкой.
Оно же доходит до плашек в верхней полосе и до полосы действий
в карточке игры, поэтому окно говорит об игре одно и то же в трёх
местах сразу.

| Файл | Что внутри |
|---|---|
| `lib/library/hero_state.dart` | `EvHeroState`, `EvHeroContent`, `EvHeroNote`, `EvInstallProgress` |
| `lib/library/hero_cta.dart` | `EvCtaNote`, `EvInstallBox`, `EvRunningPill` — то, что встаёт на место «Играть» |
| `lib/data/sample_data.dart` | `sampleHeroStates` — содержимое шести состояний |

| Состояние | На месте «Играть» | Плашки | Строка под кнопкой |
|---|---|---|---|
| Обычное | «Играть» с удержанием и «Подробнее» | приём · движок готов | — |

**Кто их переключает.** Движка нет, а состояния продукта есть, поэтому
их переключает «Настройки → Разработка → Состояние библиотеки» — тот же
список, что в панели состояний прототипа, с теми же подписями. В
продукте этого списка не будет: состояние придёт от движка. Две кнопки
уже работают по-настоящему: «Установить» переводит окно в установку,
«Завершить» — обратно в покой, а «Играть без обновления» запускает
ритуал.

**Что прячется на низком окне.** Прогресс установки и строка под кнопкой
занимают место описания, и на окне до 800 по высоте описание уходит —
ровно как в прототипе, где это делает `.hero-body.tall-cta`.

**Три знака, которых не было в выгрузке.** «Внимание», «диск» и
«выключить» нарисованы в `design/build_assets.py` — в прототипе они уже
были, но в выгрузку иконок не попадали. Источник правды один, и
`test/assets_test.dart` разбирает каждый файл.

**Тесты.** `test/states_test.dart`: полоса действий и подписи всех шести
состояний, описание на низком окне, «Установить» и «Завершить»,
переключение из «Разработки» вместе с плашками, карточка игры
в состоянии окна, «Играть без обновления». Проверены поломкой: герой,
не читающий состояние; карточка, не читающая окно; плашки, которые не
меняются; описание, которое не уступает место; «без обновления», который
не запускает; неверный процент установки; список состояний, который
ничего не переключает.


### Раздел «Загрузки»

Приборная доска раздачи. Сверху две панели: что происходит сейчас
(приём, минута истории и четыре числа) и из чего это складывается
(кольцо частей и активность пиров). Ниже — сами раздачи и очередь.

| Файл | Что внутри |
|---|---|
| `lib/downloads/download_data.dart` | `EvDownloads`, `EvTorrent`, `EvSwarmParts`, `EvTorrentAlert`, `EvQueued` |
| `lib/downloads/rate_graph.dart` | `EvRateSeries`, `EvRateGraph`, `EvPeerHeat`, `EvSwarmRing` |
| `lib/downloads/ev_torrent_row.dart` | `EvTorrentRow`, `EvAlertBox`, `EvQueueRow` |
| `lib/screens/downloads_page.dart` | Сам раздел: две панели, список, очередь |
| `lib/data/sample_downloads.dart` | Содержимое шести состояний |

**Ни одного числа в двух местах.** Приём в крупной надписи, «Отдача»,
«Активных» и «На диск» складываются из строк раздач; размер в очереди
берётся из библиотеки; проценты кольца считаются из его же гигабайтов.
Поэтому шапка не может разойтись со списком — в прототипе она
расходилась, и это чинилось там же (ниже).

| Состояние | Что говорит раздел | Плашки |
|---|---|---|
| Две активные | обычный ход, 41 % и 66 % | 1.6 МБ/с · движок готов |
| Нет раздающих | янтарная кромка, приём 0 Б/с, «искать источники» | 1.0 МБ/с · нет раздающих |
| Нет места на диске | красная кромка, сколько не хватает, «выбрать диск» | 1.0 МБ/с · диск переполнен |
| Ошибка проверки | фиолетовая кромка, 38 % вместо 41 %, «перекачать» | 2.2 МБ/с · перепроверка |
| Сеть пропала | серая кромка, прочерки вместо скоростей, отсчёт | нет сети · движок на паузе |
| Очередь пуста | пунктирная рамка и приглашение вставить ссылку | 0 Б/с · движок простаивает |

**Разбор, а не ошибка.** Полоса внутри раздачи встаёт между именем
и приборами, потому что объясняет именно приборы: сначала что случилось
и почему это не страшно, потом — что можно нажать. Цвет кодирует
причину, а не громкость: янтарь — ждём внешнего, красный — нужно решение
человека, фиолетовый — идёт работа с данными, серый — просто пауза.
Те же четыре цвета получает полоса прогресса (`EvBarTone`) и левая
кромка строки.

**Прочерк вместо нуля.** Когда сети нет, приём и отдача раздачи —
не ноль, а «—»: ноль означал бы «измерили и получили ноль». Сиды и пиры
при этом честные нули: их видно и без соединения.

**Кольцо показывает ту раздачу, которая принимает.** Если первая встала
(нет места), кольцо переходит на вторую, а не остаётся на остановленной.
Пиров нет — сетка обмена холодная целиком, а не мигает обменом, которого
не происходит.

**Приборы идут по настоящим часам.** График делает шаг раз в секунду,
сетка обмена — раз в 900 мс, как `setInterval` в прототипе; контроллер
с `AnimationBehavior.preserve`, а «уменьшить движение» их останавливает,
а не ускоряет в двадцать раз. История графика начинается с той же суммы,
которую показывает плашка в верхней полосе.

**Кто переключает состояния.** «Настройки → Разработка → Состояние
загрузок». «Сеть пропала» — не свойство очереди, а свойство окна:
включить его здесь — значит увидеть офлайн и в герое, и наоборот.
В прототипе `dl-offline` и `lib-offline` делают друг друга вручную; тут
это одно правило.

**Что поправлено в прототипе.** Раздел говорил числами, которые
не сходились:

- «Отдача 612 КБ/с» при 1.6 МБ/с и 340 КБ/с в строках — и вдобавок
  раз в секунду переписывалась случайным числом. Теперь это сумма.
- «Пик за час 7.04 МБ/с» при пике 11.0 МБ/с у одной из раздач. Пик роя
  не может быть ниже пика его части.
- Подписи кольца считались как «всего минус полученное», поэтому
  «Осталось 17.3 ГБ» не совпадало с сегментом в 33 %. Теперь это
  четыре сегмента одного круга: 11.8 + 4.9 + 2.6 + 9.5 = 28.8 ГБ.
- Строка говорила «11.5 ГБ / 28.8 ГБ» и «41 %» — это 39.9 %. И при
  перепроверке показывала 38 % рядом с теми же 11.5 ГБ.
- График приёма заполнялся случайными числами, и крупная надпись сразу
  расходилась с плашкой в полосе. Теперь последний отсчёт — сумма раздач.
- «Очередь пуста» очищала список, но ниже оставались «В очереди · 2».
  Счётчики секций тоже были вписаны руками.
- Плашка приёма в «нет сидов» показывала 0 Б/с, хотя вторая раздача
  шла на 1.03 МБ/с.

**Три знака, дорисованных к выгрузке.** «Магнит», «повтор»
и «нет сети» были в прототипе, но в выгрузку иконок не попадали;
нарисованы в `design/build_assets.py`, как и остальные 26.

**Тесты.** `test/downloads_test.dart`: суммы шапки, сходимость кольца
с подписями, пустая очередь, начало графика, все шесть состояний
с их разбором и выходом, раскладка на узком окне, переключение
из «Разработки» вместе с плашками, парность офлайна с героем. Проверены
поломкой: «на диск» равный приёму; отдача своим числом; очередь,
остающаяся в пустом состоянии; кольцо, не ищущее активную раздачу;
график не с суммы; ноль в килобайтах; офлайн, меряющий ноль; офлайн,
не доходящий до героя; плашка не из суммы; сетка обмена, мигающая без
пиров; разбор, который не показывается.

## Знак

Основной — «Отдушина»: капля пламени с белым ядром и тремя восходящими искрами.
Ядро светлее оболочки — то же подповерхностное свечение, что в кнопке запуска.

Правила: только на тёмной подложке; градиент не поворачивается, горячее всегда вверху;
ниже 20 px искры и ядро убираются, остаётся силуэт; не обводится, не кладётся на фото
и не перекрашивается в один цвет, кроме служебного монохрома. Защитное поле со всех
сторон равно высоте ядра.

Локап `lockup-horizontal.svg` прозрачен и рассчитан на тёмный фон; `lockup-horizontal-plate.svg` — тот же, но
со своей подложкой, для светлых страниц и презентаций. Слово в локапе — живой текст Unbounded: если
шрифт не установлен в системе, будет подстановка — перед печатью и передачей наружу текст нужно
перевести в кривые.

Варианты: **A · Отдушина** (основной) · **B · Призма** (для Nebula и Cryo) ·
**C · Распад капли** (анимированные заставки) · **D · Ядро** (трей, фавикон, 16 px).
